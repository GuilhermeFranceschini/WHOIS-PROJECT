### Ferramenta de consulta de domínios

Aplicação desenvolvida em Python para consultar e organizar informações públicas de registros WHOIS.

O usuário informa um domínio, e a ferramenta realiza a consulta, exibindo os dados de maneira estruturada. Entre as informações apresentadas estão o nome do domínio, o registrador responsável, as datas de criação e expiração e os servidores DNS associados.

### Tecnologias utilizadas

- Python
- Biblioteca `python-whois`

### Objetivo

O projeto foi desenvolvido como parte dos estudos de Python, redes de computadores e fundamentos de reconhecimento em cibersegurança. Durante a implementação, foram praticados conceitos como entrada de dados, estruturas de repetição, manipulação de informações e organização dos resultados obtidos por meio de consultas WHOIS.

> Desenvolvido para fins educacionais e para análise de informações públicas.
